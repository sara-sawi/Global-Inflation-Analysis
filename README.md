# Global-Inflation-Analysis
A data analysis project exploring global inflation trends from 2000 to 2025, comparing inflation rates across countries and identifying key factors affecting inflation over time.


This project was a team effort. We supported each other, shared ideas, learned together, and worked as one team to bring our project to life.
